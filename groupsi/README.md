# GROUPSI — Product Quality & QA Automation

Product quality, QA automation, UX analysis, and business logic review for GROUPSI, a live group-therapy platform in Brazil.

## Project Scope

My work on the project includes:

* Manual and exploratory testing
* JavaScript test automation with Playwright
* Functional and regression testing
* UX and user-flow analysis
* Business logic validation
* Requirements and edge-case analysis
* API testing
* Product improvement proposals

## Project Structure

* `requirements/` — requirements, user stories, acceptance criteria, business rules
* `user-flows/` — user journeys and system flows
* `ux-analysis/` — UX issues, usability findings, accessibility observations
* `test-strategy/` — test plans, test cases, regression strategy, risk analysis
* `api-testing/` — API validation and integration testing
* `automation/` — automated Playwright tests and automation documentation
* `product-improvements/` — proposed product and feature improvements

## My Role

QA Automation & Product Quality Engineer

I combine software testing, automation, product analysis, and UX thinking to identify not only technical defects but also gaps in product logic, usability, and user experience.
